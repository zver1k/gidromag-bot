# 🤖 Gidromag Telegram Bot

Telegram бот для загрузки фотографий, видео и документов оборудования на Яндекс.Диск с организацией по накладным.

## 🚀 Возможности

- 📸 Загрузка фотографий на Яндекс.Диск
- 🎥 Загрузка видео на Яндекс.Диск (до 4K, до 500MB)
- 📄 Загрузка документов на Яндекс.Диск (PDF, Word, Excel до 50MB)
- 📋 Организация по номерам накладных (поддержка кириллицы, латиницы и цифр)
- 👥 Управление доступом пользователей (хранение на Яндекс.Диске)
- 📊 Статистика использования (отдельно фото, видео и документы)
- 🔧 Административные функции
- ⚡ Интерактивное меню с inline-кнопками для быстрого создания и управления накладными
- ⏳ Автосброс накладной после 10 минут бездействия

## 📋 Команды бота

### Основные команды
- `/start` — Начать работу с новой накладной
- `/reset` — Сбросить текущую накладную
- `/cancel` — Отменить текущую накладную (псевдоним `/reset`)
- `/current` — Показать текущую накладную
- `/stats` — Показать статистику бота
- `/status` — Показать статус бота и сервисов
- `/help` — Показать справку
- `/userinfo` — Информация о пользователе
- `/menu` — Показать inline-меню с основными действиями

### Административные команды
- `/adduser <ID>` — Добавить пользователя в список разрешённых
- `/removeuser <ID>` — Удалить пользователя из списка разрешённых
- `/listusers` — Показать список всех разрешённых пользователей
- `/cleanup` — Очистка временных файлов

## 🔐 Управление доступом

### Добавить пользователя:
1. Пользователь узнаёт свой ID (отправить `/start` боту @userinfobot)
2. Администратор выполняет: `/adduser 123456789`
3. Пользователь получает доступ к боту

### Удалить пользователя:
1. Администратор выполняет: `/removeuser 123456789`
2. Пользователь теряет доступ к боту

### Список пользователей:
- Команда `/listusers` — только для администраторов

> Список разрешённых пользователей сохраняется на Яндекс.Диске (`/Фото оборудования/allowed_users.txt`) и синхронизируется при каждом запросе.

## 📖 Как использовать бота

### 1. Начало работы:
1. Отправьте команду `/start`
2. Введите номер накладной (3–50 символов: кириллица, латиница, цифры, пробел, дефис, подчёркивание)
3. Начните загружать файлы

### 2. Загрузка файлов:
- **Фотографии** — просто отправьте фото в чат
- **Видео** — просто отправьте видео в чат
- **Документы** — просто отправьте документ в чат (PDF, Word, Excel)
- Файлы автоматически сохраняются на Яндекс.Диск в папку по номеру накладной

### 3. Управление накладной:
- `/current` — посмотреть текущую накладную и количество загруженных файлов
- `/reset` или `/cancel` — завершить текущую накладную и начать новую
- `/stats` — посмотреть общую статистику бота
- `/menu` — открыть inline-кнопки с текущими действиями
- ⚡ Inline-меню подсказывает кнопку «Создать накладную», если активной накладной нет

### 4. Административные функции:
- `/adduser <ID>` — добавить пользователя
- `/removeuser <ID>` — удалить пользователя
- `/listusers` — список всех пользователей
- `/cleanup` — очистка временных файлов

## ⚙️ Установка и настройка

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Настройка переменных окружения
```bash
export TELEGRAM_TOKEN="your_telegram_bot_token"
export YANDEX_DISK_TOKEN="your_yandex_disk_token"
export WEBHOOK_URL="https://your-domain.com/"
export PORT="8443"
```

### 3. Настройка администраторов
Отредактируйте файл `config.py` и добавьте ID администраторов:
```python
ADMIN_IDS = [
    123456789,  # Ваш ID
    987654321,  # ID другого администратора
]
```

### 4. Запуск бота
```bash
python bot.py
```

## 🔧 Конфигурация

Основные настройки в файле `config.py`:

| Параметр | Значение по умолчанию | Описание |
|---|---|---|
| `MAX_FILE_SIZE` | 10 MB | Максимальный размер фото |
| `MAX_VIDEO_SIZE` | 500 MB | Максимальный размер видео |
| `MAX_DOCUMENT_SIZE` | 50 MB | Максимальный размер документов |
| `MAX_PHOTOS_PER_INVOICE` | 50 | Максимум фото на накладную |
| `MAX_VIDEOS_PER_INVOICE` | 10 | Максимум видео на накладную |
| `MAX_DOCUMENTS_PER_INVOICE` | 20 | Максимум документов на накладную |
| `BASE_FOLDER` | `Фото оборудования` | Базовая папка на Яндекс.Диске |
| `INACTIVITY_TIMEOUT_SECONDS` | 600 | Таймаут бездействия (сек) |
| `INVOICE_PATTERN` | `^[а-яА-ЯёЁa-zA-Z0-9 _-]{3,50}$` | Маска номера накладной |

## 📊 Ограничения

### Фотографии:
- Максимальный размер: 10 MB
- Максимум на накладную: 50
- Форматы: JPG, JPEG, PNG

### Видео:
- Максимальный размер: 500 MB
- Максимум на накладную: 10
- Форматы: MP4, AVI, MOV, MKV, WMV, FLV, WEBM, M4V, 3GP, 3G2, F4V, ASF
- Поддержка разрешения до 4K

### Документы:
- Максимальный размер: 50 MB
- Максимум на накладную: 20
- Форматы: PDF, DOC, DOCX, XLS, XLSX

### Общие:
- Временные файлы удаляются автоматически через 1 час
- Автосброс накладной при бездействии более 10 минут (настраивается через `INACTIVITY_TIMEOUT_SECONDS`)

## 🚨 Безопасность

- Доступ к боту только для разрешённых пользователей — проверяется в `/start`, `/help` и всех обработчиках
- Ленивая синхронизация списка пользователей с Яндекс.Диска при каждом входе
- Thread-safe изменение списка пользователей через `asyncio.Lock`
- Административные функции только для администраторов
- Валидация всех входных данных (номер накладной, форматы и размеры файлов)
- Защита от `None` в `file_size` — предотвращает `TypeError` при нестандартных файлах
- Логирование всех операций
