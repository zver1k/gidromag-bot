# 🤖 Gidromag Telegram Bot

Telegram бот для загрузки фотографий, видео и документов оборудования на Яндекс.Диск с организацией по накладным.

## 🚀 Возможности

- 📸 Загрузка фотографий на Яндекс.Диск
- 🎥 Загрузка видео на Яндекс.Диск (до 4K, до 500MB)
- 📄 Загрузка документов на Яндекс.Диск (PDF, Word, Excel до 50MB)
- 📋 Организация по номерам накладных
- 👥 Управление доступом пользователей
- 📊 Статистика использования (отдельно фото, видео и документы)
- 🔧 Административные функции
- ⚡ Интерактивное меню с inline-кнопками для быстрого создания и управления накладными
- ⏳ Автосброс накладной после 10 минут бездействия

## 📋 Команды бота

### Основные команды
- `/start` - Начать работу с новой накладной
- `/reset` - Сбросить текущую накладную
- `/current` - Показать текущую накладную
- `/stats` - Показать статистику бота
- `/status` - Показать статус бота и сервисов
- `/help` - Показать справку
- `/userinfo` - Информация о пользователе
- `/menu` - Показать inline-меню с основными действиями

### Административные команды
- `/adduser <ID>` - Добавить пользователя в список разрешенных
- `/removeuser <ID>` - Удалить пользователя из списка разрешенных
- `/listusers` - Показать список всех разрешенных пользователей
- `/cleanup` - Очистка временных файлов

## 🔐 Управление доступом

### Через команды бота:
1. Пользователь должен узнать свой ID (отправить `/start` боту @userinfobot)
2. Администратор использует команду: `/adduser 123456789`
3. Пользователь получает доступ к боту

### Как удалить пользователя:
1. Администратор использует команду: `/removeuser 123456789`
2. Пользователь теряет доступ к боту

### Как посмотреть список пользователей:
- Используйте команду `/listusers`

## 📖 Как использовать бота

### 1. Начало работы:
1. Отправьте команду `/start`
2. Введите номер накладной (3-50 символов, буквы, цифры, дефис, подчеркивание, точка)
3. Начните загружать файлы

### 2. Загрузка файлов:
- **Фотографии**: просто отправьте фото в чат
- **Видео**: просто отправьте видео в чат
- **Документы**: просто отправьте документ в чат (PDF, Word, Excel)
- Файлы автоматически сохраняются на Яндекс.Диск в папку по номеру накладной

### 3. Управление накладной:
- `/current` - посмотреть текущую накладную и количество загруженных файлов
- `/reset` - завершить текущую накладную и начать новую
- `/stats` - посмотреть общую статистику бота
- `/menu` - открыть inline-кнопки с текущими действиями
- ⚡ Inline-меню подскажет кнопку "Создать накладную", если активной накладной нет

### 4. Административные функции:
- `/adduser <ID>` - добавить пользователя
- `/removeuser <ID>` - удалить пользователя
- `/listusers` - список всех пользователей
- `/cleanup` - очистка временных файлов

## ⚙️ Установка и настройка

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Настройка переменных окружения
```bash
export TELEGRAM_TOKEN="your_telegram_bot_token"
export YANDEX_DISK_TOKEN="your_yandex_disk_token"
export WEBHOOK_URL="https://your-domain.com/"
export PORT="8443"
```

### 3. Настройка администраторов
Отредактируйте файл `config.py` и добавьте ID администраторов:
```python
ADMIN_IDS = [
    123456789,  # Ваш ID
    987654321,  # ID другого администратора
]
```

### 4. Запуск бота
```bash
python bot.py
```

## 🔧 Конфигурация

Основные настройки находятся в файле `config.py`:

- `MAX_FILE_SIZE` - максимальный размер фото (по умолчанию 10MB)
- `MAX_VIDEO_SIZE` - максимальный размер видео (по умолчанию 500MB)
- `MAX_DOCUMENT_SIZE` - максимальный размер документов (по умолчанию 50MB)
- `MAX_PHOTOS_PER_INVOICE` - максимум фото на накладную (по умолчанию 50)
- `MAX_VIDEOS_PER_INVOICE` - максимум видео на накладную (по умолчанию 10)
- `MAX_DOCUMENTS_PER_INVOICE` - максимум документов на накладную (по умолчанию 20)
- `SUPPORTED_PHOTO_FORMATS` - поддерживаемые форматы фото
- `SUPPORTED_VIDEO_FORMATS` - поддерживаемые форматы видео (до 4K)
- `SUPPORTED_DOCUMENT_FORMATS` - поддерживаемые форматы документов
- `BASE_FOLDER` - базовая папка на Яндекс.Диске
- `ADMIN_IDS` - список ID администраторов
- `INACTIVITY_TIMEOUT_SECONDS` - таймаут бездействия для автосброса накладной (по умолчанию 600 секунд)

## 📊 Ограничения

### Фотографии:
- Максимальный размер: 10MB
- Максимум фото на накладную: 50
- Поддерживаемые форматы: JPG, JPEG, PNG

### Видео:
- Максимальный размер: 500MB
- Максимум видео на накладную: 10
- Поддерживаемые форматы: MP4, AVI, MOV, MKV, WMV, FLV, WEBM, M4V, 3GP, 3G2, F4V, ASF
- Поддержка разрешения до 4K

### Документы:
- Максимальный размер: 50MB
- Максимум документов на накладную: 20
- Поддерживаемые форматы: PDF, DOC, DOCX, XLS, XLSX

### Общие ограничения:
- Автоматическое удаление временных файлов через 1 час
- Автосброс накладной: если после ввода накладной нет активности более 10 минут, бот сбрасывает состояние и просит ввести номер накладной заново (настраивается через `INACTIVITY_TIMEOUT_SECONDS`)

## 🎥 Технические детали видео

### Поддерживаемые форматы:
- **MP4** - основной формат, рекомендуется для 4K
- **AVI** - классический формат
- **MOV** - формат Apple, хорош для 4K
- **MKV** - открытый формат, поддерживает высокое качество
- **WebM** - веб-оптимизированный формат
- **M4V** - формат iTunes
- **WMV, FLV, 3GP, 3G2, F4V, ASF** - дополнительные форматы

### Рекомендации:
- Для 4K видео рекомендуется использовать MP4 или MOV
- Максимальный размер файла: 500MB
- Автоматическое определение формата по расширению
- Поддержка всех популярных кодеков

## 📄 Технические детали документов

- **DOC/DOCX** - документы Microsoft Word

### Рекомендации:
